CFA STUDY READER — VERSIÓN 4

Esta versión recupera el diseño del lector anterior y añade cursos completos desde PDF.
Tu config.js ya contiene la URL y la clave pública de Supabase que proporcionaste.
Si Supabase ya funcionaba, esta actualización NO necesita otro SQL ni un proyecto nuevo.

ACTUALIZA CON GITHUB DESKTOP
1. En la web actual, exporta un respaldo desde Ajustes. Conserva también una copia de la carpeta del repositorio.
2. Descomprime el ZIP. Copia el CONTENIDO de CFA_Study_Reader_v4 dentro de la carpeta local de tu repositorio index.html.
3. Acepta reemplazar archivos. Conserva .git y CNAME si tienes un dominio propio. No borres la carpeta del repositorio.
4. index.html, config.js, app, vendor, styles.css y .github deben quedar directamente en la raíz, sin otra carpeta intermedia.
5. En GitHub Desktop: revisa los cambios, escribe «Lector PDF y cursos completos», pulsa Commit y después Push origin.
6. En GitHub > Settings > Pages conserva GitHub Actions. Espera a que el despliegue termine y abre la misma dirección de tu web.
7. Actualiza la página con Ctrl+F5. Inicia sesión con la misma cuenta; tus datos existentes se conservan.

PRIMER LIBRO
1. Pulsa Cargar PDF, selecciona el libro y pulsa Crear curso de lectura.
2. Se crea automáticamente un curso con módulos y una lectura por cada página física.
3. Abre Ver índice y cobertura. Si hace falta, ajusta títulos y rangos desde Ajustar módulos y rangos.
4. Lee en PDF original: sus gráficos, fórmulas, tablas y anexos permanecen en el archivo original.
5. Marca páginas estudiadas, guarda notas y crea tarjetas. Espera a que termine la sincronización antes de cambiar de dispositivo.

LÍMITES CLAROS
Hasta 40 MB y 1.000 páginas por PDF. El texto extraído es auxiliar; la detección del índice puede necesitar correcciones.
Un escaneo conserva todas sus páginas, pero su OCR se solicita por página desde el lector; no se reconoce todo el libro automáticamente.
Si estás en «Solo este dispositivo», tus datos son locales: inicia sesión para usar la nube. Exporta e importa un respaldo si quieres trasladar datos del espacio local a tu cuenta.
